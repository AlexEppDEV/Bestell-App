Eine interaktive Web-App zum Bestellen von Gerichten mit Warenkorb, dynamischem Rendering und LocalStorage.

## ✨ Features

- 📋 Dynamisches Menü aus JavaScript-Daten
- 🛒 Warenkorb mit:
  - Hinzufügen von Gerichten
  - Mengenänderung (+ / −)
  - Löschen von Items
- 💾 Speicherung im LocalStorage
- 📱 Responsive Design (Mobile, Tablet, Desktop)
- 🎨 Interaktive UI mit Hover-Effekten
- 🔢 Automatische Preisberechnung
- 🧾 Bestell-Dialog nach Abschluss

---

## 🧠 Gelernt / Konzepte

- Dynamisches Rendering mit Templates
- Trennung von Logik und UI
- Arbeiten mit Arrays und Objekten
- Event Handling (Click Events)
- DOM Manipulation (`innerHTML`, `classList`)
- LocalStorage (`JSON.stringify`, `JSON.parse`)
- Responsive Design mit Media Queries

---

## 🧑‍💻 Technologien

- HTML5
- CSS3 (Flexbox, Variablen, Media Queries)
- JavaScript (Vanilla JS)
